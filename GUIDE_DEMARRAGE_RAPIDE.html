npx http-server .

🔧 Personnalisation

Changer les Données

Ouvrez lord-system-pwa.html et trouvez la section mockData:

const mockData = {
  mosque: [
    { name: 'Votre mosquée', dist: '0.5 km', ... }
  ],
...

Intégrer une Vraie API

Remplacez les `mockData` par des appels fetch() à votre backend:

const response = await fetch('/api/locations?category=mosque');
const data = await response.json();
displayResults('mosque', data);

❓ FAQ - Dépannage

Q: L'app ne s'installe pas

A: Vérifiez que vous utilisez HTTPS (localhost OK pour test). Rechargez la page (Ctrl+Shift+R).

Q: Les données ne chargent pas offline

A: Ouvrez DevTools (F12) → Application → Cache Storage. Vérifiez que le cache existe.

Q: Comment utiliser ma propre API?

A: Voir section "Intégration" du README.md. Remplacez `mockData` par vos endpoints.

Q: Puis-je ajouter plus de catégories?

A: Oui! Duplique une carte, changez l'icône et l'ID. Ajoutez les données correspondantes.
