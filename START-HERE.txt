🚀 DÉMARRAGE RAPIDE (5 minutes)
===============================

Étape 1: Test local
─────────────────
Placez les 3 fichiers essentiels dans un dossier:
- index.html
- manifest.json
- sw.js

Ouvrez votre terminal dans ce dossier et lancez:

   Python 3:    python -m http.server 8000
   Node.js:     npx http-server
   PHP:         php -S localhost:8000

Puis ouvrez: http://localhost:8000

Étape 2: Testez sur votre téléphone
──────────────────────────────────
Via le même réseau local:
   Android: Ouvrez http://IP-DE-VOTRE-PC:8000 dans Chrome
   iPhone:  Ouvrez http://IP-DE-VOTRE-PC:8000 dans Safari

Étape 3: Installez l'app
──────────────────────
Android:  Menu (⋮) → "Installer l'app"
iPhone:   Partage (↗️) → "Sur l'écran d'accueil"

Étape 4: Testez offline
──────────────────────
1. DevTools (F12) → Network
2. Cochez "Offline"
3. Rechargez la page
4. L'app fonctionne sans internet! 🎉

❓ QUESTIONS FRÉQUENTES
======================

Q: Pourquoi HTTPS?
R: Le Service Worker nécessite HTTPS pour des raisons de sécurité.
   Les services cloud (Vercel, Netlify, etc) l'incluent.

Q: Fonctionne offline?
R: Oui, les pages visitées et les assets sont en cache.
   Les appels API ne fonctionnent que online (normal).

Q: Comment mettre à jour?
R: Modifiez les fichiers et uploadez-les. Les utilisateurs
   verront la mise à jour au prochain rechargement.

Q: Puis-je ajouter des notifications?
R: Oui, c'est possible via Push Notifications API
   (consulter la documentation avancée).

Q: Taille maximale du cache?
R: ~50 MB pour les images, ~10 MB pour les scripts
   (configurable dans config.js).
