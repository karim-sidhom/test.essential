WORKFLOW RECOMMANDÉ
===================

1️⃣ DÉVELOPPEMENT LOCAL
   ├─ Utilisez 3 fichiers essentiels (html, manifest, sw)
   ├─ Lancez: python -m http.server 8000
   ├─ Testez à http://localhost:8000
   └─ Testez offline via DevTools

2️⃣ PERSONNALISATION
   ├─ Éditez les couleurs dans index.html (:root)
   ├─ Modifiez manifest.json (nom, icônes)
   ├─ Ajustez config.js (langue, services)
   └─ Testez à chaque changement

3️⃣ TESTING
   ├─ Chrome DevTools (F12 → Application)
   ├─ Vérifiez Service Worker actif
   ├─ Testez offline mode
   ├─ Test d'installation (menu du navigateur)
   └─ Test sur 2-3 navigateurs

4️⃣ DÉPLOIEMENT
   ├─ Choisissez une plateforme:
   │  - Vercel (recommandé - gratuit)
   │  - Netlify (gratuit)
   │  - GitHub Pages (gratuit, limité)
   │  - Serveur privé (Apache/Nginx)
   │
   ├─ Utilisez la config appropriée:
   │  - Vercel → vercel.json
   │  - Nginx → nginx.conf
   │  - Apache → .htaccess
   │
   └─ Vérifiez HTTPS (obligatoire)

5️⃣ LANCEMENT
   ├─ Partagez l'URL
   ├─ Testez sur appareils réels
   ├─ Installez l'app sur écran d'accueil
   └─ Célébrez! 🎉


FICHIERS PAR CAS D'USAGE
=======================

Cas: Test local rapide
└─ Besoin: index.html + manifest.json + sw.js
   Commande: python -m http.server 8000

Cas: Déployer sur Vercel
├─ Uploadez les 3 fichiers essentiels
├─ Utilisez vercel.json (optionnel)
└─ Vercel configure automatiquement HTTPS

Cas: Déployer sur Netlify
├─ Drag & drop le dossier
├─ Netlify compile automatiquement
└─ HTTPS inclus

Cas: Serveur Apache/cPanel
├─ Uploadez les 3 fichiers essentiels
├─ Placez .htaccess dans le dossier racine
├─ Activez mod_rewrite
└─ Vérifiez HTTPS

Cas: Serveur Nginx
├─ Uploadez les 3 fichiers essentiels
├─ Éditez nginx.conf
├─ Relancez Nginx
└─ Vérifiez HTTPS

Cas: Serveur Docker
├─ Utilisez une image nginx
├─ Copiez la config nginx.conf
├─ Exposez le port 443 (HTTPS)
└─ Mount le dossier /var/www

Cas: Personnalisation complète
├─ Commencez par config.js
├─ Éditez les variables
├─ Testez localement
└─ Déployez

DÉPANNAGE RAPIDE
================

Problème: "Impossible d'installer"
Solution:
  1. Utilisez HTTPS (pas HTTP)
  2. Vérifiez /manifest.json accessible
  3. Attendez 5+ secondes
  4. Rechargez (Ctrl+Shift+R)

Problème: "Service Worker gris"
Solution:
  1. Rechargez la page
  2. Videz le cache (F12 → Clear site data)
  3. Cherchez les erreurs console

Problème: "Offline ne fonctionne pas"
Solution:
  C'est normal pour les appels API!
  Les pages HTML visitées sont en cache.

Problème: "Manifest pas trouvé"
Solution:
  1. Vérifiez que manifest.json existe
  2. Vérifiez le chemin dans index.html
  3. Vérifiez le Content-Type: application/json
